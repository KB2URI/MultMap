# MultMap

MultMap is an amateur radio contest multiplier mapping and tracking companion for N1MM Logger+ on Windows.

## Availability

MultMap is currently in development. No public application or contest-package release is available yet. Approved downloads and release notes will appear on the [Releases page](https://github.com/KB2URI/MultMap/releases).

## Support MultMap

See [Support and feedback](SUPPORT.md) for how to ask questions, report problems or suggest improvements. Please do not post personal information or complete contest logs in public issues.
