# Support and feedback

MultMap is not yet publicly released. This repository is the home for future approved downloads, release notes and user support.

- [Search existing issues](https://github.com/KB2URI/MultMap/issues) before opening a new one.
- [Report a bug or suggest an improvement](https://github.com/KB2URI/MultMap/issues/new/choose).
- For usage questions, open an issue with a clear description of what you need help with.

When reporting a problem, include the MultMap version (if available), Windows version, N1MM Logger+ version, contest and a short description of the expected and actual behavior. Include steps to reproduce the problem where possible.

Issues and attachments are public. Remove callsigns, contact details, private file paths, credentials, station or network details and other personal information before posting. Do not upload complete log databases or raw support bundles.
